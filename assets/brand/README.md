# FollowAudit brand

The official artwork lives in this folder as SVG. The PNG icons in `public/` are rendered from these files.

| File | Use |
| --- | --- |
| `followaudit-logo.svg` | Horizontal logo for light backgrounds |
| `followaudit-logo-dark.svg` | Horizontal logo for dark backgrounds |
| `followaudit-mark.svg` | Symbol only (favicon, app icon, avatars) on light backgrounds |
| `followaudit-mark-dark.svg` | Symbol only on dark backgrounds |

## Name

Always write **FollowAudit** — one word, capital F and A. In the logo, “Follow” uses the ink color and “Audit” uses the brand gradient.

## Colors

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| Ink | `#172235` | `#F4F7FB` | Text, main person in the mark |
| Blue | `#0A5CFF` | `#1F5FFF` (solid) / `#6198FF` (text) | Primary actions, links, selection |
| Cyan | `#0AA3EC` | — | Gradient midpoint |
| Teal | `#12C7B4` (graphic) / `#0A7D72` (text) | `#26CDB9` | Success, protection, check badge |
| Soft gray | `#C3CCDD` | `#C9D2E3` | Secondary person in the mark |
| Background | `#F5F7FB` | `#0A111E` | Page background |

Brand gradient: `linear-gradient(90deg, #0A5CFF, #0AA3EC 55%, #12C7B4)`.

## Typography

[Manrope](https://fonts.google.com/specimen/Manrope) (SIL OFL). The wordmark is ExtraBold (800) with tight tracking. The interface embeds a Latin subset as WOFF2 (`public/fonts/manrope-latin.woff2`, `src/assets/manrope-latin.woff2`).

## Clear space and sizes

Keep clear space around the logo equal to the height of the check badge. Do not use the horizontal logo below 120 px wide; use the mark instead. Do not recolor, stretch, rotate, or add effects to the artwork.
